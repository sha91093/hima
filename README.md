# 地番名寄せシステム

手入力で管理されてきた不規則な地番データを、SISの地番表示に自動変換するツールです。

「全自動を目指さず、プログラムが下処理したものを人間が最終確認する」ワークフローで設計しています。

## 動作環境

- Python 3.11以上
- 完全オフライン動作
- 低スペックPCでも軽快に動作

## セットアップ

```bash
pip install pandas openpyxl
```

モダンなGUIにしたい場合（オプション）：

```bash
pip install customtkinter
```

## 必要なファイル

| ファイル | 内容 | 形式 |
|---|---|---|
| 入力ファイル | 現場管理Excel（手入力の地番データ） | `.xlsx` `.xls` `.csv` |
| マスターCSV | SISからエクスポートした正解地番一覧 | `.csv` |

## 使い方

### GUIモード（通常業務用）

```bash
python main.py
```

#### 操作手順

1. **入力Excel/CSV** の「参照」ボタン → 現場管理ファイルを選択
2. **地番列** → 地番が入っている列番号を入力（0始まり。2列目なら `1`）
3. **SISマスターCSV** の「参照」ボタン → SISの正解地番CSVを選択
4. **「変換＆突合を実行」** ボタンを押す

#### 結果の見方

| 色 | 判定 | 意味 |
|---|---|---|
| 緑 | 完全一致 | そのまま出力してOK |
| 黄 | 推測成功 | 枝番展開等で一致。念のため確認 |
| 赤 | 判定不能 | 手動で正しい地番を選ぶ必要あり |

#### 判定不能の手動マッチング

1. 赤い行を **ダブルクリック**
2. 下の検索窓に候補が表示される（なければキーワードを入力して「検索」）
3. 候補リストから正しい地番を選んで **「選択した候補で確定」**

#### 出力

- **「結果をCSV出力」** → 変換前後の比較表（確認・記録用）
- **「SISインポート用CSV出力」** → SISに取り込む最終CSV

### CLIモード（テスト・確認用）

対話的に1件ずつ試す：

```bash
python main.py --cli

# 例: "１２３−１、２、３" と入力すると
#   → 123-1
#   → 123-2
#   → 123-3
```

ファイルを一括処理：

```bash
python main.py --cli \
  -i 現場管理.xlsx \
  -m SISマスター.csv \
  --chiban-col 1 \
  --master-chiban-col 2 \
  --master-oaza-col 0 \
  -o 結果.csv
```

### CLIオプション一覧

| オプション | 説明 | デフォルト |
|---|---|---|
| `--cli` | CLIモードで動作（GUIなし） | - |
| `-i`, `--input` | 入力Excel/CSVファイルパス | - |
| `-m`, `--master` | SISマスターCSVファイルパス | - |
| `-o`, `--output` | 出力CSVファイルパス | - |
| `--chiban-col` | 入力ファイルの地番列（列番号 or 列名） | `0` |
| `--master-chiban-col` | マスターの地番列 | `0` |
| `--master-oaza-col` | マスターの大字列 | なし |

## 対応する手入力パターン

| 入力（手入力のクセ） | 変換結果 |
|---|---|
| `三本木１２３−１、２、３` | `三本木123-1, 三本木123-2, 三本木123-3` |
| `三本木　１２４ー１　借り` | `三本木124-1` |
| `大平沢２００−１ア・イ・ウ` | `大平沢200-1-ア, 大平沢200-1-イ, 大平沢200-1-ウ` |
| `三本木百二十五の一部` | `三本木125` |
| `大平沢201-1,2,3 外` | `大平沢201-1, 大平沢201-2, 大平沢201-3` |
| `大平沢202-1付近の加藤の田んぼ` | `大平沢202-1` |

### 正規化の処理内容

- **文字統一**: 全角数字→半角、漢数字→算用数字、全角スペース→削除
- **ハイフン統一**: 全角ハイフン・長音符・ダッシュ → 半角ハイフン
- **不要キーワード削除**: 「借り」「作」「所有」「外」「の一部」等を除去
- **枝番補完**: `1-1,2,3` → `1-1, 1-2, 1-3`
- **分筆カナ補完**: `200-1ア` → `200-1-ア`
- **古い表記変換**: `123の1` → `123-1`
- **大字分離**: SISマスターの大字名で前方一致分離

## 業務ワークフロー

```
SISから正解地番をCSVエクスポート
        ↓
  このツールで変換＆突合
        ↓
  緑・黄 → 自動で確定
  赤   → 画面でポチポチ選ぶ
        ↓
  SISインポート用CSVを出力
        ↓
   SISにCSVインポート
```

## ファイル構成

```
main.py                          # エントリポイント（GUI/CLI両対応）
land_parcel_normalizer/
  __init__.py
  normalizer.py                  # 地番正規化・展開エンジン
  converter.py                   # Excel/CSV読み込み・変換パイプライン
  matcher.py                     # SISマスター突合・あいまい検索
  gui.py                         # GUI（CustomTkinter/tkinter両対応）
tests/
  test_normalizer.py             # ユニットテスト
sample_data/
  input_sample.csv               # サンプル入力データ
  master_sample.csv              # サンプルSISマスター
```

## はじめかた

まずは `--cli` モードで手元のデータを数件試して、変換精度を確認するところから始めてください。

```bash
python main.py --cli
```

うまく変換できないパターンが見つかったら、`normalizer.py` の `DEFAULT_REMOVE_KEYWORDS` にキーワードを追加したり、正規化ルールを調整して対応できます。
